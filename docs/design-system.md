# Estándar visual de Correspondencia SV

Referencia: [Dock — Style Reference](style-reference.md)

## Archivos activos

- `layout.css`: distribución, tamaños compactos, adaptación y animaciones, sin colores
- `theme.css`: única fuente activa de colores, tipografía y apariencia de componentes

Las hojas de estilo históricas no se cargan en `index.html`

## Reglas

- Fondo crema `#faf9f7`, superficies marfil `#fbfaf7` y blanco `#ffffff`
- Texto principal `#121722`, texto secundario `#777c86`
- Único color de acciones: cobalto `#0068f9`; hover `#024bb1`
- Botones secundarios blancos, sin colores de acción adicionales
- Violeta `#6736eb` reservado a etiquetas de énfasis y una métrica decorativa
- Estados distinguidos por texto e iconos con superficies neutras; no paletas de colores por tipo de correspondencia
- Bordes finos `#efefef` y separación azul tenue `#d6e4f1`
- Tarjetas de 16 px de radio, botones tipo píldora de 48 px, iconos circulares
- Inter como alternativa abierta a Roobert, sin cargar fuentes con licencia no disponible
- Sombras neutras y ligeras; ningún resplandor de color
- Se mantiene la densidad compacta de una aplicación de gestión, en lugar de las dimensiones de una landing comercial

Los flujos de envío, la validación de identidad y las reglas funcionales no dependen de estos estilos
